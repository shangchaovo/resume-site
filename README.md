# 简历工坊 Resume Forge

面向**在校大学生**的纯前端简历制作工具 —— 打开网页就是编辑器，左边填表、右边实时看到一张 A4 简历，写完直接导出高清 PDF 去面试。

无需注册、无需联网（首屏字体走 CDN 但可降级）、数据全部存在你自己的浏览器里。

## 它能做什么

- **三套模板**，一键切换
  - **简约现代单栏** —— 通用，适合大多数岗位（默认）
  - **经典双栏** —— 左侧深色信息栏，适合技术 / 设计岗
  - **学术深造** —— 衬线标题、GPA 高亮、科研 / 论文分区，适合保研 / 出国
- **6 种专业配色** × **3 档密度**（紧凑 / 标准 / 宽松），同一份内容自由换肤
- **实时 A4 预览**：所见即所得，超出一页时屏幕出现红色折页线 + 徽章提醒
- **完成度清单**：自动检查 11 项（手机号 / 邮箱格式、是否量化、是否倒序、是否一页…），点哪条跳到哪个输入框并闪一下
- **写作指南**：内置「一页纸原则 / STAR+量化公式 / 动词词库 / 常见减分项」等 6 章，照着改就有校招味
- **多草稿**：一份简历投不同岗位？复制成多份分别改
- **照片上传**：自动压缩，不撑爆浏览器存储
- **JD 关键词对照**：粘贴岗位描述，透明列出「已覆盖 / 还缺」的词（**不是** ATS 玄学分数），词典没收录的还能手动加
- **空心句检测 + 分类型示例**：标出「负责 / 参与」开头却没结果的弱句，按实习 / 项目 / 社团 / 科研给示例句和动词库
- **本地投递看板**：把每份简历版本和每次投递串起来，拖卡片改状态，数据存本机
- **JSON 备份**：导出 / 导入，换电脑或清缓存都不丢

## 启动

```bash
cd ~/campus-resume-builder
node server.js
# 浏览器打开 http://localhost:8769
```

首次打开会自动填入一份**示例简历**（前端校招范本），你可以直接照着改成自己的经历，或点「填入示例」随时恢复。

## 导出 PDF（重点）

工具用浏览器**原生打印**导出，所以文字是矢量、可选中、文件小、颜色准：

1. 点右上角红色 **导出 PDF**
2. 在弹出的打印对话框里：
   - 目标 / 打印机 → **另存为 PDF**
   - 纸张 → **A4**
   - 边距 → **无**
   - 展开「更多设置」→ 勾选 **背景图形**（否则双栏模板的左栏底色不显示）
3. 保存。建议文件名用 `姓名-学校-应聘岗位.pdf`

> 也可以用系统快捷键 `⌘P` / `Ctrl+P` 直接打印，效果一样。

## 写好校招简历的 5 条速记

1. **一页纸**。HR 看一份简历平均 6–10 秒，第二页基本看不到。
2. **每条经历 = 动词 + 做了什么 + 量化结果**。
   - ✗ 负责公众号运营
   - ✓ 策划 12 场裂变活动，6 个月粉丝 0 → 8000+（+400%）
3. **倒序**，最近的写最前面；时间格式统一 `2025.07 – 2025.10`。
4. **照镜子**：把岗位 JD 的关键词圈出来，简历用同样的词回应；不同岗位准备不同版本。
5. **不放空话自评、不放自拍、不用百分比技能条**。

完整的写作指南在编辑器右上角「写作指南」抽屉里。

## 写作小贴士（字段级）

- 经历描述**一行一条**，每条动词开头，尽量带数字（%、万、人次、倍、天）。
- 技能用「熟练 / 熟悉 / 了解」分层，别画进度条。
- 求职意向写明确，如「前端开发工程师（2026 届校招）」。
- 照片用正式证件照；没有就不放，别用滤镜自拍。

## 和付费工具的不同

对照一份「大学生简历/求职平台」研究报告，付费工具最常被骂的几件事，我们要么不做、要么反过来做：

- **不自动续费、没有试用陷阱** —— 完全免费，不存在「7 天试用后悄悄扣款」。
- **无水印、导出不设限** —— 浏览器原生打印导出矢量 PDF，文字可选中、颜色准确，不锁下载、不加水印。
- **关键词是「透明对照」，不是玄学 ATS 分** —— 粘贴 JD 后，只列出「哪些词已覆盖、哪些还缺」，由你判断怎么自然补，**不给无法解释的总分**。
- **不产「漂亮但空心」的 AI 句** —— 内置空心句检测和分类型示例，提醒你「动词后面要带方法和结果」；但事实由你核验。报告也说：AI 适合打草稿，不适合替代你的判断。
- **简历 + 投递闭环** —— 本地投递看板把每份简历版本和每次投递串起来，补上多数模板工具缺的「投了之后」这一环。

> 报告里属于另外三类产品的能力（LinkedIn 经营、面试题库、岗位分发、真人代写）我们没有塞进来——那是不同的产品，硬塞只会四不像。

## 数据存储

所有内容保存在浏览器 `localStorage`（键名以 `crb:` 开头）。**清除浏览器数据会丢失**，所以重要简历请定期点「导出 JSON」备份一份到本地。

## 自动常驻（可选）

想让电脑开机就自动跑在 8769：

```bash
mkdir -p ~/Library/Logs/campus-resume-builder
cp launchd/com.campus-resume-builder.server.plist ~/Library/LaunchAgents/
launchctl load -w ~/Library/LaunchAgents/com.campus-resume-builder.server.plist
```

卸载：`launchctl unload -w ~/Library/LaunchAgents/com.campus-resume-builder.server.plist`

## 技术栈

纯 HTML / CSS / 原生 JS，零依赖、零打包；一个零依赖的 Node 静态服务器。简历排版用本地系统字体栈，保证导出的 PDF 在任何电脑上都长一个样。

## 公网访问

已部署到 Cloudflare Pages，电脑关机也能打开：**https://resume-5lv.pages.dev/**

- 改完代码想更新公网版：`bash scripts/deploy-pages.sh`（首次需 `npx wrangler login` 一次性浏览器授权）。
- 想让自己的域名也叫 resume（如 `resume.你的域名`）：在 Cloudflare 给这个 Pages 项目加「自定义域」即可，免费、即时生效。
- 为什么不是 `resume.pages.dev`：这个免费子域名已被他人占用（共享命名空间），所以自动带了 `-5lv` 后缀，不是 bug。
