# 简历工坊

准备校招简历时，在左侧填经历，右侧就能看到 A4 排版，写完可保存为文字能选中的 PDF。

**从示例改第一条经历。** [打开简历工坊](https://resume-5lv.pages.dev/)，把首次出现的前端校招示例改成自己做过的项目，看预览如何随文字换行。网页版无需安装或注册。

## 写完一份，再为不同岗位改版

- **先写经历。** 每行写一件事，交代自己做了什么、怎么做、结果如何。遇到只有「负责」「参与」却没写结果的句子，编辑器会标出并提供同类示例。「完成度清单」还能核对联系方式、经历顺序等项目，右上角「写作指南」可查 STAR 写法和动词示例。
- **再看一页能否放下。** 可选通用单栏、经典双栏、学术深造三套模板，搭配六种配色和三档密度。预览有页数徽章和折页线，超页时可先删减与目标岗位关系最小的内容。
- **为下一份投递复制草稿。** 粘贴岗位描述（JD），查看简历已覆盖和仍缺少的关键词，只补自己确有经历的内容。该工具给出逐词对照，不计算 ATS 总分。在「投递看板」中选关联的简历版本，拖动卡片即可更新进度。

## 把当前版本交给招聘方

1. 点右上角 **导出 PDF**，或按 `⌘P` / `Ctrl+P`。
2. 在浏览器打印窗口选 **另存为 PDF**、纸张 **A4**、边距 **无**。勾选 **背景图形**，尤其是双栏模板，否则左栏底色可能消失。
3. 检查打印预览的页数后保存，例如 `姓名-学校-岗位.pdf`。浏览器直接打印简历正文，文字可选中，导出不加水印。

## 哪些数据能带到另一台电脑

简历草稿、照片和投递看板保存在当前浏览器的 `localStorage`（`crb:`）。编辑与关键词对照都在浏览器内完成。打开页面会从 Google Fonts 请求界面字体，加载失败时使用系统字体。

**「导出 JSON」只备份当前草稿。** 换浏览器、换电脑或清除站点数据前，逐份切换并导出要保留的版本；在新浏览器点「导入 JSON」会创建一份新草稿。投递记录单独存在 `crb:apps`，清除站点数据会一并清除，简历 JSON 无法恢复这些记录。

## 在本机运行

在仓库根目录运行以下命令，无需安装 npm 包或打包前端。

```bash
node server.js
```

打开终端打印的地址，默认是 `http://localhost:8769`。默认端口被占用时服务会再试 `8770`。本机站点和在线站点各自保存草稿，可用 JSON 在两者之间移交。

macOS 登录自启可参考 [launchd 模板](launchd/com.campus-resume-builder.server.plist)。先将其中的 Node、项目和日志路径换成本机实际路径，再载入 LaunchAgent。自行部署到 Cloudflare Pages 时先用 `npx wrangler login` 授权，并核对脚本中的项目名和代理设置。[部署脚本](scripts/deploy-pages.sh)
