简历写作指南

校招 · 实习 · 保研
01一页纸原则

校招简历坚持一张 A4 纸。HR 筛选一份简历平均只用 6–10 秒，两页意味着第二页大概率不会被看到。

内容取舍标准：与目标岗位相关的经历详写，不相关的（如应聘开发时的家教经历）一笔带过或直接删掉。荣誉只保留含金量最高的 3–5 项。

02STAR + 动宾 + 量化

每条经历用「动词 + 做了什么 + 通过什么方法 + 量化结果」的句式：

✗ 负责社团公众号运营

✓ 负责社团公众号运营，通过策划 12 场裂变活动与栏目改版，6 个月内粉丝从 0 增长至 8000+（+400%），篇均阅读量提升 3 倍

量化维度：数量、百分比、金额、时间周期、覆盖人次、排名。没有精确数字就用量级（近百人、数十场）。

按类型抓重点：

  • 实习：业务影响 + 工程指标（性能、覆盖率、节省人日）
  • 项目：从 0 到 1 的角色 + 技术难点 + 用户/数据结果
  • 社团 / 志愿：组织规模 + 你推动的变化（转化率、覆盖人次）
  • 科研：方法 + 基准提升 + 你的具体贡献（一作 / 二作）
03倒序与时间线

所有经历最近的写在最前面。时间格式统一用「2025.06 – 2025.09」。

超过 3 个月的空窗期要能解释（备考、休学创业等），面试时主动说明比被追问更好。

04岗位匹配：照镜子

投递前把 JD（岗位描述）里的关键词圈出来，简历用同样的词汇回应。JD 写「熟悉 Vue」，你就不要只写「会前端」。

不同岗位准备不同版本：技术岗突出项目与技术栈，运营岗突出数据与活动，一份简历投所有岗位是大忌。

05动词开头词库

主导 · 搭建 · 优化 · 落地 · 策划 · 重构 · 推动 · 迭代 · 制定 · 整合 · 孵化 · 复盘 · 拉通 · 沉淀 · 赋能 · 攻坚

开头永远用动词，避免「我」「我们」「负责了」这类弱开头。「参与」显得被动，换成具体承担的部分。

06常见减分项
  • 自我评价写空话（「吃苦耐劳、团队精神」）——要么用一句话给出证据，要么不写
  • 照片用自拍/滤镜照——要正式证件照，或干脆不放
  • 错别字与标点混用（中英文标点混杂）
  • 文件名是「简历.pdf」——用「姓名-学校-应聘岗位.pdf」
  • 技能用进度条/百分比表示（「PS 80%」没有意义）
